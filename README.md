# Библиотека для работы с биологическими форматами (FASTA, FASTQ, SAM, VCF)

Библиотека на Python для парсинга и базового анализа основных биологических форматов данных. 
Проект написан без использования профильных библиотек (Biopython, pysam и т.д.) — только стандартная библиотека Python, а также `pandas` и `matplotlib` для статистики и визуализации.

## Что умеет

Проект построен на основе иерархии абстрактных классов (ООП) и использует **генераторы** для эффективного чтения больших файлов (без загрузки всего файла в память).

- **`Reader`** — базовый абстрактный класс, задающий интерфейс `read()`.
- **`SequenceReader`** — базовый класс для работы с последовательностями (FASTA, FASTQ).
- **`GenomicDataReader`** — базовый класс для геномных данных (SAM, VCF).

Наследники:
- **`FastaReader`** — читает FASTA. Умеет считать количество последовательностей и их среднюю длину.
- **`FastqReader`** — читает FASTQ. Умеет считать статистику и строить график качества (Per base sequence quality) с помощью `matplotlib`.
- **`SamReader`** — читает SAM. Парсит заголовки (`@PG`, `@RG`, `@SQ`), считает количество выравниваний, строит статистику по хромосомам (через `pandas`), находит выравнивания в заданном регионе (учитывая CIGAR).
- **`VcfReader`** — читает VCF. Парсит мета-строки (`##INFO`, `##FORMAT`), считает количество вариантов, строит статистику по регионам (через `pandas`), ищет варианты в заданном регионе.

## Установка

Клонируйте репозиторий и установите зависимости:

```bash
git clone https://github.com/VvediteNickname/Classes-for-FASTA.git
cd 14_Bio_Data

python -m venv .venv
source .venv/bin/activate       # Linux / macOS
.venv\Scripts\activate          # Windows

pip install pandas matplotlib

## Запуск демо

```bash
python demo.py
```
