Техническая документация

Назначение

Программный комплекс предназначен для чтения файлов биоинформатических форматов и получения сводной информации об их содержимом. Поддерживаемые форматы относятся к двум группам: нуклеотидные последовательности (FASTA и FASTQ) и геномные записи (SAM и VCF).

Входные данные

Входом является текстовый файл соответствующего формата. В FASTA содержатся идентификаторы и нуклеотидные последовательности. В FASTQ к последовательности добавляются строка-разделитель и символьные оценки качества. SAM содержит записи выравнивания прочтений на референсную последовательность. VCF хранит сведения о вариантах генома и метаданные, описывающие файл и его поля.

Результаты обработки

В зависимости от выбранного формата программа предоставляет информацию о содержимом файла. Для SAM доступны сводка по хромосомам и выборка выравниваний по геномному интервалу. Для VCF доступны сведения из заголовка, число вариантов, группировка вариантов по координатным окнам и выборка по региону. Для последовательностей предусмотрены подсчёт записей и средней длины; для FASTQ также предусмотрена визуализация качества по позициям.

Интервалы генома

В реализации обработки SAM и VCF координаты региона задаются именем хромосомы и начальной и конечной позициями. Границы интервала включаются в выборку. Для SAM длина выравнивания на референсе определяется по CIGAR-строке; для VCF интервал варианта зависит от позиции и длины референсного аллеля.
