Запуск проекта
--------------

Команды ниже приведены для Linux и Ubuntu. Выполняйте их из каталога проекта.

**1. Создайте виртуальное окружение и активируйте его:**

.. code-block:: console

   python3 -m venv .venv
   source .venv/bin/activate

**2. Установите библиотеки, необходимые для обработки данных:**

.. code-block:: console

   python -m pip install pandas matplotlib

**3. Запустите демонстрационную программу:**

.. code-block:: console

   python demo.py

В ответ на запрос формата введите ``sam`` или ``vcf``, затем выберите тестовый файл: ``sample.sam`` или ``sample.vcf``. Эти варианты представлены в репозитории.

О проекте
---------

**14_Bio_Data** — программа для чтения и анализа файлов с биологическими данными. Она предназначена для получения информации о последовательностях нуклеотидов, геномных выравниваниях и вариантах генома в зависимости от формата входного файла.

Для форматов SAM и VCF предусмотрены чтение заголовков и записей, подсчёт записей, сводная статистика и получение записей, относящихся к заданному геномному региону. Для FASTA и FASTQ в проекте предусмотрена обработка последовательностей; для FASTQ также реализовано построение графика оценок качества.
