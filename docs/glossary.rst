Краткая научная справка
=======================

**Нуклеотидная последовательность** — упорядоченная цепочка нуклеотидов ДНК или РНК. Её запись в текстовом виде позволяет передавать последовательности между программами и базами данных.

**Референсный геном** — выбранная эталонная последовательность генома, с которой сопоставляют экспериментальные прочтения. Референс служит системой координат для описания положения выравниваний и вариантов.

**Выравнивание последовательности** — размещение прочтения относительно референса с указанием совпадений, замен, вставок или удалений. SAM — один из форматов текстового представления таких записей.

**Генетический вариант** — отличие последовательности образца от выбранной референсной последовательности. VCF предназначен для записи вариантов и связанных с ними сведений, например альтернативного аллеля, качества и аннотаций.

**Оценка качества FASTQ** — символьное представление оценки достоверности прочтения нуклеотида. Такие оценки помогают выявлять позиции, для которых секвенирование могло быть менее надёжным.

**Геномный регион** — участок референсной последовательности, задаваемый хромосомой и координатами. Поиск записей в заданном регионе позволяет рассматривать не весь файл, а конкретный участок генома.
